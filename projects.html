Operating system

AOS

My own operating system. Not a Linux skin, not a theme. A real 64-bit OS that boots through UEFI and runs on a Rust kernel.

  • A full-color desktop with a taskbar and a searchable Start menu
  • Built-in Files, Notes, Write, Terminal, Programs and a Store
  • Runs its own native .AIS apps
  • Keyboard, mouse and its own FAT12 file system
  • Builds into a bootable ISO (tested in QEMU)
  • Rust
  • x86-64
  • UEFI
  • Kernel

AstroArena

An open-source game made to be very close to Brawl Stars, built so anyone can clone it, fork it and make it their own. No game engine: every fighter, arena, sound and song is generated in code.

  • 5 fighters (Spark, Bark, Kira, Kito and Buddy), each with a super and a Hyper
  • Last Spark free-for-all, Knockout Rush 3v3, Boss Mode, 1v1 against real players, and a Training Area
  • Arena Boxes, Cups, upgrades, the Spark Road and a shop
  • Smart bots, from Easy to Elite
  • Custom OpenGL ES 3.0 graphics and its own Python game server
  • Kotlin
  • OpenGL ES
  • Android
  • Python
  • Open source
